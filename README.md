 # JavaScript Platform Game

## Overview
This platform game is inspired by *Dark Blue* by Thomas Palef ([original game](http://www.lessmilk.com/games/10)). It offers a minimalist yet engaging gameplay experience, designed with simplicity and efficiency in mind.

## Gameplay Mechanics
- 🎮 **Player Controls** – Move left/right with arrow keys, jump with the up arrow
- 🟡 **Coin Collection** – Collect all yellow boxes to complete a level
- 🔥 **Avoid Obstacles** – Steer clear of red elements (lava) to survive
- 🦘 **Dynamic Movement** – High jumps and midair direction change for fluid control

## Game Structure
- The game features a **static grid-based background**, serving as the main layout.
- The **moving elements** include:
  - Player (dark box)
  - Coins (yellow boxes)
  - Lava (red elements, including moving pieces)
- Positions are **not constrained** to the grid—fractional coordinates allow smooth motion.

## Technologies Used
- JavaScript (Core Game Logic)
- HTML5 Canvas (Rendering)
- CSS (Styling and UI)
